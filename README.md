# Ứng Dụng Nhắc Nhở Học Tập

## 1. Giới thiệu
Ứng dụng hỗ trợ học sinh / sinh viên quản lý thời gian biểu, theo dõi kế hoạch học tập và tạo các thông báo nhắc nhở nhiệm vụ hằng ngày.

## 2. Công nghệ sử dụng
- **Ngôn ngữ / Nền tảng:** Flutter (Dart) / Mobile App
- **Cơ sở dữ liệu & Dịch vụ:** Firebase / SQLite
- **Mô hình kiến trúc:** MVC / Provider quản lý trạng thái (State Management)

## 3. Các chức năng chính
- Quản lý danh sách công việc, bài tập (Thêm / Sửa / Xóa / Đánh dấu hoàn thành).
- Thiết lập thông báo nhắc hẹn và đếm ngược thời gian làm bài (Countdown).
- Lưu trữ và đồng bộ trạng thái công việc.
- Giao diện trực quan, tối ưu trải nghiệm người dùng trên thiết bị di động.
